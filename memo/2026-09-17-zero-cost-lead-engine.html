법적 검토 결론

이 구조는 의료광고법 위반이 아닙니다

Zero-Cost Lead Engine은 광고비를 집행하지 않고, 해외 고객이 스스로 검색해 들어오는 가격 안내 웹사이트입니다. 아래 근거로 현행 의료법상 허용되는 범위 안에서 운영됩니다.

① 가격 공개는 의무입니다

의료법 제45조·시행규칙 제42조의2 제4항에 따라 홈페이지를 운영하는 의료기관은 비급여 가격을 홈페이지에 표시해야 합니다.

② 사전심의 대상이 아닙니다

의료법 제57조·시행령 제24조의 심의 대상 매체(신문·방송사 홈페이지, 일 이용자 10만 명 이상 매체·SNS 등)에 자체 도메인 웹사이트는 포함되지 않습니다.

③ 국내광고 금지 조항에 해당하지 않습니다

해외 언어·해외 오가닉 검색으로만 운영하고 국내 광고를 집행하지 않으며, 뷰티블라썸의원은 외국인환자 유치기관으로 등록되어 있습니다(시행령 제23조 제1항 제12호).

④ 같은 구조가 이미 운영 중입니다

더나의원, 리베리의원, 클림의원, 원셀의원 등이 공식 홈페이지와 분리된 가격 키워드 도메인에 원화 가격과 상담 폼을 두고 구글 오가닉으로 운영하고 있습니다.

지켜야 할 조건: 정가·이벤트가·기간·대상을 한 블록에 표기, 최상급·효과 보장·무료·신청 혜택 표현 금지, 치료경험담 금지, 부작용·개인차 고지. 세부 기준은 아래 법조항 표와 워딩 가이드에 정리했습니다.

가격을 보여주는 것은 불법이 아닙니다

오히려 법이 요구하는 일입니다. 의료법 제45조는 의료기관이 비급여 진료비용을 환자가 쉽게 알 수 있도록 고지하게 하고, 같은 법 시행규칙 제42조의2 제4항은 홈페이지를 운영하는 의료기관은 비급여 항목과 가격을 홈페이지에 따로 표시하도록 정하고 있습니다.

실제로 2021년 비급여 고지 의무가 의원급까지 확대된 뒤, 관할 보건소가 홈페이지에도 비급여 비용을 안내하라고 연락한 사례가 보도됐습니다.

문제가 되는 것은 가격 그 자체가 아니라 가격을 보여주는 방식입니다. 할인 금액·대상·기간이나 할인 전 가격을 거짓 또는 불명확하게 적는 것(의료법 시행령 제23조 제1항 제13호), 무료·과도한 할인으로 환자를 끌어들이는 것(의료법 제27조 제3항)입니다.

광고를 집행하지 않은 검색 유입 페이지의 법적 위치

이 기획은 광고비를 쓰지 않고, 소비자가 스스로 검색해서 클릭한 경우에만 페이지에 들어옵니다. 이 점이 법적으로 어떤 의미가 있는지 조항별로 정리했습니다.

먼저 짚을 점: 의료법 제56조 제1항은 의료광고를 "신문·잡지·음성·음향·영상·인터넷·인쇄물·간판 그 밖의 방법으로 의료기관 정보를 소비자에게 알리는 행위"로 정의합니다. 그래서 광고비를 쓰지 않은 홈페이지도 의료광고에 해당하고, 내용 규제는 그대로 적용됩니다. 대신 자발적 검색 유입 구조는 사전심의 의무와 국내광고 금지 조항에서 벗어나는 근거가 됩니다.

시술마다 서브도메인 하나를 "독립된 가격 홈페이지"처럼 운영합니다. 이벤트가 바뀌어도 주소는 그대로 두고 가격만 교체해, 같은 주소에 검색 순위가 쌓이게 합니다.

1안: 신규 .com 1개 + 시술별 서브도메인

  • 예: 대표 도메인 blossomskinclinic.com 아래 ultherapy.blossomskinclinic.com, thermage.blossomskinclinic.com (시술 이름은 도메인이 아니라 서브도메인에만 들어갑니다)

  • .kr의 "한국 대상" 신호가 없어 해외 노출에 중립적
  • 확인된 경쟁 병원 4곳 모두 공식 사이트와 분리된 별도 도메인 사용
  • 가비아에서 구매 후 네임서버만 Cloudflare로 변경 (새 도메인이라 옮길 기존 레코드 없음)

2안 (비용 0원 대안): beautyblossom.kr 서브도메인

  • 예: ultherapy.beautyblossom.kr
  • 가비아 DNS에서 레코드만 추가, 추가 비용 없음
  • 기존 도메인 권위를 활용해 초기 노출이 빠를 수 있음

대표 도메인명: 신뢰형 키워드 기반

대표 도메인은 시술명이 아니라 병원 신뢰도를 주는 이름으로 정하고, 시술은 그 아래 서브도메인으로 붙입니다. 해외 사용자의 구글 자동완성에서 반복 확인된 검색어를 기준으로 골랐습니다. (2026년 9월 17일 조회)

해외 사용자가 실제로 쓰는 신뢰형 검색어

  • korea skin clinic → seoul, gangnam, myeongdong, recommendations, reddit 등으로 확장
  • seoul skin clinic → for foreigners, reviews, appointments
  • korean aesthetic clinic → seoul, singapore, london
  • korea clinic → aesthetic, beauty, skin, rejuran

공통 핵심어는 "skin clinic", "korea/seoul"입니다.

  • blossomskinclinic.com (추천) — 병원명 + 핵심어. 실제 운영 병원이 드러나 신뢰도와 광고 투명성을 동시에 확보
  • koreabeautyclinic.com (차선) — "korea clinic beauty" 검색어와 일치하는 일반 명칭
  • seoulkskinclinic.com, kskinclinicseoul.com — 짧은 K-스킨 계열
  • koreaskinclinicseoul.com — 최다 검색어 "korea skin clinic" 포함 (다소 김)
  • koreanaestheticclinic.com — "korean aesthetic clinic" 검색어와 일치
  • hapjeongskinclinic.com — 지역형

이미 등록된 이름: koreaskinclinic.com, seoulskinclinic.com, koreanskinclinic.com, seoulaestheticclinic.com, koreahospital.com, koreaclinic.com 등

도메인명에 넣지 않을 단어

  • hospital: 뷰티블라썸은 의원이라 "병원"으로 읽히는 이름은 사실과 다르게 보일 수 있음
  • dermatology: 피부과 전문의원으로 오인될 수 있음. "skin clinic"이 검색어로도 더 많이 쓰임
  • guide·foreigners·official 계열: 중립 안내 사이트나 공공기관처럼 보일 수 있음
  • 시술명·price: 대표 도메인이 특정 시술 판매 사이트처럼 보이고 스팸처럼 인식될 수 있음

.clinic 같은 신규 도메인(예: beautyblossom.clinic)도 등록 가능하지만 연장비가 .com보다 크게 높아 1안에서는 .com을 유지합니다.

고객이 들어와서 예약되기까지

  1. 검색

    자국어로 "한국 울쎄라 가격"을 검색하고, 가격이 드러난 제목을 보고 클릭합니다.

  2. 가격 확인

    첫 화면에서 정가, 이벤트가, 기간을 바로 봅니다.

  3. 채팅 시작

    페이지 안 채팅창을 열면 이름과 답변 받을 곳(WhatsApp·LINE·이메일)을 먼저 남기고 상담원과 대화합니다. 창을 닫거나 한국 시간 밖이어도 고객이 고른 수단으로 답변이 이어집니다.

  4. DB 저장

    이름, 국가, 답변 받을 곳(WhatsApp·LINE·이메일), 메신저 ID, 관심 시술, 희망 날짜, 방문 유형, 유입 페이지, 이관 채널이 구글시트 한 곳에 쌓입니다.

    신청 폼의 방문 유형 선택

    • 시술 예약 방문 — 진료 후 바로 시술 진행 (대기 시간이 짧아요)
    • 상담 후 결정 — 진료·상담을 받고 시술 여부 결정 (대기 시간이 생길 수 있어요)

    두 유형 모두 시술 전 원장 진료를 거치며, 시술 가능 여부는 진료 결과에 따라 달라질 수 있다는 문구를 선택란 아래에 함께 표기합니다. 유형 선택에 따른 가격 혜택은 두지 않습니다.

  5. 담당자 배정

    국가별로 해외마케팅 팀원에게 자동 배정되고, 영업시간 안에 사람이 이어받습니다.

  6. 예약 확정

    방문 유형에 맞춰 일정을 확정합니다. "시술 예약 방문"은 시술 시간까지 함께 잡아 대기를 줄이고, "상담 후 결정"은 진료·상담 시간을 먼저 잡습니다.

상담원은 이렇게 응대합니다

  • 관리 화면(웹) 또는 모바일 앱에서 모든 랜딩의 대화를 한 곳에서 받음
  • 대화마다 유입 URL이 표시되어 시술·언어를 바로 파악 (예: 일본어 울쎄라 페이지)
  • 언어·국가별로 해외마케팅 팀원에게 배정
  • 대화 중 받은 연락처는 통합 DB 시트에 기록하고 연락완료 체크

고객이 채팅창을 닫아도 놓치지 않는 구조

웹 채팅은 고객이 창을 닫으면 같은 브라우저로 다시 들어오기 전까지 답변을 볼 수 없습니다. 그래서 대화를 시작하기 전에 "답변 받을 곳"을 먼저 받고, WhatsApp·LINE으로 상담을 이어갑니다.

① 채팅 시작 전 입력창

  • 이름
  • 답변 받을 곳 선택: WhatsApp 번호 / LINE / 이메일
  • 개인정보 수집·이용 동의

입력과 동시에 통합 DB 시트에 한 줄이 추가됩니다 (유입 URL, 선택한 연락 수단 포함). 창을 닫아도 DB는 이미 확보된 상태입니다.

② 창을 닫았을 때 답변 경로

  • 이메일: 상담원 답변이 이메일로 자동 전달되고, 고객이 메일로 답장하면 채팅 인박스로 다시 들어옵니다.
  • WhatsApp: 담당자가 무료 WhatsApp Business 앱에서 해당 번호로 직접 이어서 상담합니다. (API 미사용, 0원)
  • LINE: 공식계정은 친구 추가한 고객에게만 메시지를 보낼 수 있어, LINE 선택 시 채팅창에 "친구 추가하고 답변 받기" 버튼을 바로 띄웁니다. 친구 추가 후 1:1 채팅 답장은 무료입니다.
  • 같은 브라우저로 재방문: 대화가 남아 있어 채팅창에서 그대로 이어집니다.

운영 규칙: 대화가 끊기면 담당자가 고객이 고른 수단으로 이어받고, DB 시트에 "이관 채널"을 기록합니다.

③ 실시간 채팅 가능 시간 안내 (추후 구현 · 1차 오픈 범위 제외)

  • 채팅 버튼과 채팅창 상단에 표시: "실시간 채팅 상담 ○○:○○~○○:○○ (한국 시간)"
  • 고객 현지 시간 병기: 방문자 기기 시간대를 읽어 "현지 시간 ○○:○○~○○:○○"을 함께 보여줍니다. (예: 일본은 한국과 같은 시각, 대만·홍콩·말레이시아는 1시간 이른 시각, 태국·베트남은 2시간 이른 시각. 한국 10:00 = 태국 08:00)
  • 운영 시간 안: "지금 상담 가능합니다" 표시 후 바로 대화
  • 운영 시간 밖: "지금은 상담 시간이 아닙니다. 연락처를 남겨주시면 ○○시 이후 순서대로 답변드립니다" 안내와 함께 ① 입력창으로 연결
  • 표기 언어: 각 랜딩 언어로 번역해 표시하고, 운영 시간은 진료 시간·팀원 근무 시간에 맞춰 확정합니다.

비용이 생기는 경우 (2차 단계에서 검토)

  • WhatsApp API 연동: 메시지를 채팅 인박스에 모으거나 자동 발송하려면 WhatsApp Business Platform(API)을 써야 하며, 2026년 10월 1일부터는 고객 문의에 답하는 메시지도 번호당 월 1,000건을 넘으면 과금됩니다. 링크 버튼 + 무료 WhatsApp Business 앱 직접 응대는 비용이 없습니다.
  • LINE 단체 발송: 1:1 채팅 답장은 무료 발송 건수에 포함되지 않지만, 친구 대상 일괄 메시지는 무료 플랜 기준 월 200건까지입니다.
  • Chatwoot 안에 메신저 연결: 결국 각 메신저 API를 쓰는 구조라 위 과금이 그대로 적용됩니다.

채널 선택

  • 메신저 연결형: LINE·WhatsApp 버튼. 가장 빠르게 시작할 수 있고 이탈이 적음
  • 웹 채팅 위젯형: 페이지 안에서 대화. 어떤 시술 페이지에서 들어왔는지 기록됨
  • 통합 인박스: LINE, WhatsApp, 웹 채팅을 한 화면에서 응대. 도입 전에 채널 연동 범위 확인
  • AI 1차 응대 (2차 단계): 가격, 예약 가능일, 위치 안내까지만. 강남언니 자동응대 로직 재활용

채팅에서 하지 않는 것

  • 사진을 보고 시술을 추천하는 등 진단·처방성 답변
  • "결과 보장", "가장 저렴" 같은 표현
  • "오늘 채팅하면 추가 할인" 같은 신청 혜택
  • AI 응대라는 사실을 숨기는 것
  • 받은 얼굴 사진을 기한 없이 보관하는 것

광고비 없이 트래픽을 만드는 방법

검색

  • 시술 × 국가 가격 롱테일 키워드로 페이지 확장
  • 서치콘솔 등록, sitemap, hreflang(언어 간 연결)
  • MedicalClinic + Offer 구조화 데이터
  • 기존 en·jp·tw·th 사이트의 시술 페이지에서 가격 페이지로 내부 링크

이미 가진 채널

  • 국가별 인스타·유튜브 쇼츠 프로필 링크와 영상 설명란
  • LINE 공식계정 리치메뉴에 가격 페이지 연결
  • 구글 비즈니스 프로필 웹사이트 링크
  • 리뷰 답글과 해외 커뮤니티 답변에서 자연스럽게 연결

오픈 전 확인 목록

  • 정가, 이벤트가, 기간, 대상을 한 블록에 같이 표기
  • 검색결과 제목과 설명에는 할인율을 넣지 않음
  • "BEST", "최고" 같은 최상급 표현은 쓰지 않음
  • 가짜 신청 현황 롤링은 넣지 않음
  • 국내 대상 광고는 집행하지 않고 해외 오가닉으로만 운영
    국내 광고 자체가 불법은 아닙니다. 다만 해외 환자용 랜딩을 국내에 광고하면 "외국인환자 유치 목적 국내광고 금지"(의료법 시행령 제23조 제1항 제12호)에 해당한다는 주장이 나올 수 있어, 경쟁 병원의 무분별한 신고나 네거티브 공세에 빌미를 주지 않기 위한 사전 방어 조치입니다.
  • 폼: 필수 동의와 마케팅 동의 분리, 기본값은 체크 해제
  • 개인정보처리방침에 채팅 솔루션과 해외 서버를 위탁·국외이전으로 명시
  • 채팅창에 한국 기준 응대 시간 표시 (AI 도입 시 AI 응대 표시 추가)
  • 부작용·개인차 고지, 병원 사업자 정보 표기
  • 첫 화면에 "뷰티블라썸의원 운영 사이트" 표기
  • vercel.app 등 임시 주소는 최종 도메인으로 리다이렉트

진행 순서

  1. 1~2주차: 대표 도메인 등록 + 첫 시술 페이지 파일럿

    가비아 .com 등록, 네임서버 Cloudflare 변경, 첫 시술(울쎄라)을 대표 도메인의 서브도메인으로 만들어 일본어·번체중국어(대만) 페이지 오픈, 채팅·폼·시트 저장 흐름 검증, 색인 요청

  2. 1개월차: 시술 10개로 확장

    시술별 고유 콘텐츠 작성, 워딩 검수, 공식 사이트에서 내부 링크, 쇼츠 설명란 연결

  3. 2개월차: 언어 확장

    조사 결과 기준 2단계 홍콩(번체 콘텐츠 공유, 홍콩식 표기로 교체)·싱가포르(영어) 추가

  4. 3개월차: 성과 판단

    노출·DB·예약 전환 확인 → 서브도메인 10개씩 추가 여부, AI 자동응답 도입 여부, 채팅 가능 시간 안내(현지 시간 병기) 구현 시점 결정

보는 숫자

  • 색인된 페이지 수
  • 검색 노출과 클릭률
  • 채팅 시작률
  • 월 DB 건수
  • DB 대비 예약 확정률
  • 국가별 내원 수
  • 오가닉 DB 비중
  • 메타 포함 통합 ROAS
  • 메타 DB 대비 예약 전환율 차이

  2. 채팅 도구 운영 순서 확정 (tawk.to 오픈 → Chatwoot 전환 시점), Chatwoot를 올릴 PC와 관리 담당

  6. 1차로 올릴 시술 10개
